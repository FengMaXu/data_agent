## 本次实现

1. 编写 `方案.md`，明确采用生产级工具目录检索，而不是硬编码规则路由。
2. 新增 `src/agent/tool_search.py`：
   - 内置 `tool_search`。
   - 支持 `select:<tool_name>` 精确加载。
   - 支持关键词、`+required` 必选词、英文/snake_case/camelCase/中文意图检索。
   - 匹配工具名称、label、description、参数名和参数说明。

   - `tool_catalog` 保存完整工具目录。
4. 调整 `AgentContextBuilder`：
   - 新增 `known_tools`，用于历史工具调用清洗。
   - 当前可见工具只有 `tool_search` 时，历史 `execute_sql` 等调用仍可保留。
5. 调整 `agent_loop`：
   - 每次 LLM 调用前刷新 `context.tools = tool_catalog.visible_tools()`。
   - `tool_search` 执行后，下一轮 LLM 自动看到新加载工具 schema。
   - 未加载工具误调时，错误提示建议先使用 `tool_search`。

   - 首轮模型请求只传 `tool_search` schema。

   - 在 `run_start/status(preparing)` 后立即发送无 `message_id` 的 `text_delta`，让前端 pending 气泡立刻显示文本。
   - 新增 `first_visible_text`、`model_tool_count`、`full_tool_count`、`deferred_tool_count` 等观测字段。
7. 调整前端 SSE 类型：

- Updated `dashboard_compiler` to compile `series_by` long-form data into aligned independent ECharts series with stable x-axis categories and optional grouped color mapping.
- Updated `dashboard_template.html` so dashboards without filters preserve the compiler-generated ECharts option, and filtered cartesian charts rebuild using the same `series_by` / `where` semantics instead of falling back to naive `y_columns`.
- Updated project and global dashboard skill instructions with the `series_by` and `series[].where` contract.
- Added `tests/test_dashboard_grouped_series.py` covering grouped long-form series, duplicate-field validation, explicit `where` filters, template preservation, `_raw` recovery, and edit operation aliases.

## 2026-05-18 Dashboard Filter Default Fix

## 2026-08-12：P3 ownership 与自动删除隔离第一批

### Decision

### Implemented

- KTX 增加 SQLite artifact ownership 索引，记录 owner connection/source、target connection、raw paths 和内容哈希。

- provenance 增加 `removed` action 和最终 artifact 内容哈希；eviction_list 生产路径改用 ownership + 当前内容哈希。

- MetricFlow deterministic projection 为 semantic model/cross-model metric 保留声明文件路径，并把精确 `artifactRawPaths` 接入 bundle provenance/ownership；无精确依赖的 projection 不自动申请 ownership。
- MetricFlow projection 在 declaration file 删除时，只有 ownership、当前内容哈希和全部 raw dependencies 同时满足才删除 source；手工修改或仍有 retained dependency 时 fail-closed。
