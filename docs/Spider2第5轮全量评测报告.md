# Spider2 第 5 轮全量评测报告

## 1. 结论摘要

第 5 轮 SQLite 全量评测完成 **135/135** 题，最终运行无基础设施失败。相比第 4 轮，替换为改进版 System Prompt 后总体正确率没有提升：

- SQL EX（固定 135 题）：**56 → 49**，下降 7 题、5.19 个百分点；
- E2E EX（固定 135 题）：**55 → 49**，下降 6 题、4.44 个百分点；
- CSV 交付：**123 → 120**，下降 3 题；
- completed：**123 → 114**，下降 9 题；
- `max_turns`：**1 → 5**，`timeout`：**11 → 16**。

因此，本次提示词替换在当前评测设置下未验证出收益，结果更接近第 3 轮的正确率（49/135），而不是第 4 轮的 55/135。由于模型调用不具备固定随机种子，第 4→第 5 轮的差异不能全部归因于提示词；但运行状态、CSV 交付和错误类型均显示第 5 轮行为稳定性明显变差，暂不建议直接以该提示词替代第 4 轮版本作为已验证改进。

## 5. 新提示词的行为信号

### 5.1 提示词中的工具清单与实际可用工具存在条件差异

改进版提示词完整列出了 `ask_user_clarification`、KTX 三个工具以及其他可选工具。运行时虽然会追加实际能力提示，但基础提示词仍然会让模型看到这些名称。第 5 轮轨迹中出现：

- `ask_user_clarification` 不存在错误：2 次；
- 第 4 轮没有该类不存在工具调用。

这说明“提示词中的完整工具参考表”和“当前评测 Harness 实际注册工具”之间仍存在冲突。对于按需工具，应在基础提示词中明确“仅当当前工具列表实际提供时可用”，或由运行时能力合同覆盖并避免模型优先尝试不可用工具。

### 5.2 文件路径指引出现新错误

第 5 轮出现：

- `ENOENT`：5 次；
- `EISDIR`：2 次。

第 4 轮对应的 `ENOENT`/知识文件路径错误为 0。新提示词规定 `read_file` 读取工作区，但 SQL 路由又要求读取知识文件；模型在两套路径/工具语义之间发生了混用，例如将 `db_schema.md` 或 `doc/business.md` 作为工作区路径读取。该问题可能消耗额外轮次并造成超时。

### 5.3 导出前一致性校验仍有较大重试成本

第 5 轮共记录：

- `EXPORT_SQL_NOT_VALIDATED`：62 次；
- 查询 `MCP_TOOL_ERROR`：43 次；
- SQL 执行超时错误：5 次；
- `FORBIDDEN_SQL`：3 次。

第 4 轮对应的导出一致性错误为 67 次，查询错误为 50 次。虽然第 5 轮保护触发次数略降，但没有转化为更高正确率；因此不能把减少保护错误等同于质量提升。

## 6. 评测结论

1. **第 5 轮未达到第 4 轮水平。** E2E `55 → 49`，回到第 3 轮的绝对正确数。
2. **改进版提示词在当前形态下不应直接视为有效改进。** 其内容更完整，但工具条件、知识文件路径和可选能力的表达不够精确，可能引发路由错误。
3. **交付稳定性下降。** completed `123 → 114`，timeout `11 → 16`，max-turns `1 → 5`，CSV `123 → 120`。
4. **第 4 轮的部分提升具有明显随机性或不稳定性。** 第 5 轮回归了第 4 轮的多个新增正确题，因此需要重复运行确认，而不能只看一次全量结果。
5. **SQL 语义仍是主要瓶颈。** 第 5 轮虽然 SQL 覆盖为 100%，但只有 49 题正确；提示词长度和规则数量增加没有解决业务口径、聚合粒度及时间边界问题。

## 7. 建议

1. 暂不将第 5 轮提示词作为已验证默认版本；保留第 4 轮结果和第 5 轮作为对照实验。
2. 修正提示词工具表：将 KTX、`ask_user_clarification`、Python、Widget、Dashboard 明确标为“仅当运行时工具列表实际存在时可用”，不要让静态表看起来像全部已注册。
3. 统一知识文件访问规则：知识文档只能通过 `search_knowledge`/`read_knowledge` 读取，工作区文档只能通过 `read_file` 读取，避免模型把两种路径混在一起。
4. 对第 5 轮 14 个 E2E 回归题做轨迹审计，尤其是 `local020`、`local007`、`local077`、`local202` 和 `local344`，确认是提示词路由、SQL 语义还是超时导致。
5. 下一轮至少在相同并发、相同模型和相同运行时快照下重复 3 次；用均值、标准差和逐题稳定通过率判断提示词收益。
