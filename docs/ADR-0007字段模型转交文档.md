# ADR-0007 字段模型：转交文档

更新：2026-10-10

## 目标

把 Answer Spec 的模型接口和领域模型收敛为"字段 + 证据"两个概念，取代现在并存的槽位、决策点、假设、Choice 四套写法。

- **第一阶段（已实现，在开关后）**：模型只用 `set_answer_spec` 按字段路径写口径，运行时再把字段编译为旧记录。
- **第二阶段（设计中）**：领域记录本身收敛为字段记录，目标结构见 ADR-0007 的"第二阶段的目标模型"补充。

## 当前进度

### 已完成

| 事项 | 结果 |
| --- | --- |
| 第一阶段 A/B（10 道开发集题，deepseek-flash） | 新接口整次调用报错率 29% → 2%，到达 Ready 6/10 → 8/10，正确率 4/10 → 5/10；样本小，正确率差 1 题，不足以下结论 |
| 修复 `output.rowMode` 文档缺失（PR #161，已合并） | 新接口字段被拒率 41% → 25% |
| 第二阶段目标模型（PR #162，已合并） | 字段树 18 个节点，分结构、状态、必要性、层四个维度；附规则映射、路径迁移和实施顺序 |
| 用 135 道标准口径检验字段树（已写入 #162） | 61 种属性都能表达；据此改为可嵌套的度量表达式，删掉聚合顺序和单位节点，修正触发规则，补上 `op` 枚举 |

### 进行中

**错题归因**（人工进行）：118 道历史错题，清单见 `evaluations/spider2/adr0007/wrong-118.csv`，其中 55 道从未答对过。

每道题标 3 项：

- **分叉节点**：字段树 18 个节点中最早分叉的一个，放不进任何节点的标"树外"。
- **错误层**：口径错、实现错、方言或数据错、标准答案有问题。
- **可见性**：未声明、误标不适用、题面引用错、假定错、待定后决定错。

## 下一步

1. **汇总错题归因**，回答三个问题，结论补进 ADR-0007：
   - 字段树有没有缺口（"树外"错题的数量和类型）；
   - `population.eligibility`、`population.timeField`、`population.missing` 是否保留（标准口径检验覆盖不到这三个节点）；
   - 必要性规则是否漏检：错误所在节点按规则本该要求声明、但实际没声明的有多少。
2. **完整 A/B**：按 ADR 规定在 35 道开发集题上跑两组，建议放宽 8 分钟超时；正确率不回退即可把 ADR 状态改为 accepted。
3. **切换默认接口**：默认改为 `fields`，删除 `begin_answer_spec`、`revise_answer_spec` 和 `answer-spec` Skill，更新 `.pi/SYSTEM.md`。
4. **给 Hypothesis 和 Choice 加显式 `path` 属性**，取代按 statement 前缀识别归属的做法。改动小，不迁移数据。
5. **第二阶段收敛**：可嵌套的 `measure.formula`、`op` 枚举、必要性规则。旧快照只读投影，JEV 接口经投影保持不变。
6. **实现 Schema Profile**，让物理层字段（数据来源、时间字段、连接放大）由运行时核实，不再由模型假定。

可选小项：`answer-fields` Skill 里的 `ranking` 写法也像 `rowMode` 一样列出可选值（重跑中仍有 3 次 `Invalid ranking facet value`）。

## 运行与复现

```bash
# A/B 一组（另一组把 fields 换成 legacy）
node evaluations/spider2/run.mjs run --config evaluations/spider2/config.local.json \
  --model-profile deepseek --ids-file evaluations/spider2/adr0007/adr0007-dev10-ids.txt \
  --spec-interface fields --disable-clarification --run-id <run-id>
node evaluations/spider2/run.mjs score --config evaluations/spider2/config.local.json \
  --model-profile deepseek --run <run-id>

# 两组对比（ADR 规定的四项指标）
python evaluations/spider2/adr0007/adr0007_compare.py <legacy-run-id> <fields-run-id>

# 字段树对照标准口径
python evaluations/spider2/adr0007/field_tree_coverage.py -v
```

- 运行前先构建：`npm run build:contracts && npm run build:charts && npm run build:runtime && npm run build:transport && npm run build:server`。
- 本地配置：`config.local.json` 的 `deepseek` 档已改为 `deepseek-flash`；密钥在 `evaluations/spider2/.env.local`（不入库）。该密钥曾在对话中明文出现，**需要作废后重新生成**。
- 已有 run（`C:/data-agent-eval/runs/`）：
  - `adr0007-legacy-dev10-deepseek-flash-20261010`
  - `adr0007-fields-dev10-deepseek-flash-20261010`（修复前）
  - `adr0007-fields-rowmode-dev10-deepseek-flash-20261010`（修复后）
