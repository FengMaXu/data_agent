# 揭示前独立题解
题面："How many users are there in each age category (20s, 30s, 40s, 50s, and others)?"。
按mst_users用户计数，年龄为参考日时已经过的完整生日周年数。20s=20..29，30s=30..39，40s=40..49，50s=50..59；其他包含剩余年龄及缺失/无效生日。题面没有参考日；没有业务文档提供截止日，故默认查询当日（真实SQLite date('now')确认后固定记录，不用任意历史年份迎合Gold），这是假定不是业务事实。全部master用户包括withdraw_date已填者，因为题面没说只活跃。生成5个分类，空分类补0，以回答each；按用户键distinct计数、验证键唯一。检查生日格式是否可解析、生日在参考日以后、withdraw范围，必要时披露不能确认的资格。
备选参考注册日、数据最后日志日期是不同业务问题或快照假定；实际测算敏感性，不能把观测日期当权威业务日。
